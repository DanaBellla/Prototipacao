# Frontend BandaConnection

O site estático fica em `public/`. Para abrir, carregue `public/index.html` no
navegador. Não é necessário instalar pacotes ou iniciar o backend.

Alternativamente, a partir da raiz do repositório, execute:

```bash
python3 -m http.server 8000 --directory frontend/public
```

e acesse <http://localhost:8000>.
