# BandaConnection

Protótipo de plataforma que conecta músicos, estabelecimentos e ouvintes.

## Abrir o site

Abra [`frontend/public/index.html`](./frontend/public/index.html) no navegador.
O site é feito em HTML, CSS e JavaScript puro e não precisa instalar dependências
nem iniciar o backend.

Se preferir servir o site localmente, na pasta do projeto execute:

```bash
python3 -m http.server 8000 --directory frontend/public
```

Depois, acesse <http://localhost:8000>.
